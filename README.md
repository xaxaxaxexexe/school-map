# Школы Чеченской Республики

Веб-приложение для мониторинга школ Чеченской Республики. Дашборд со статистикой по районам и интерактивная карта на Яндекс.Картах.

Работает полностью на клиенте — сервер не нужен. Данные загружаются из Excel-файла прямо в браузере.

## Стек

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 4
- Redux Toolkit
- Яндекс.Карты 2.1
- SheetJS (xlsx) — парсинг Excel на клиенте
- PWA (офлайн-поддержка)

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка

```bash
npm run build
npm run preview
```

Готовый билд в `dist/` — можно хостить как статический сайт (GitHub Pages, Netlify, Vercel и т.д.).

## Загрузка данных

1. Перейти на `/admin`
2. Загрузить `.xlsx` файл (drag-and-drop или клик)
3. Файл парсится в браузере и сохраняется в localStorage
4. Данные доступны на дашборде (`/`) и карте (`/map`)

## Формат Excel

Файл `.xlsx`. Первая (или первая непустая) строка — заголовки. Парсер ищет колонки по названию, регистр и пунктуация неважны, порядок произвольный.

### Обязательные колонки

| Заголовок | Тип |
|-----------|-----|
| Название школы | Текст |
| Сменность | Число |
| Мощность | Число |
| Количество обучающихся | Число |
| Количество работников | Число |
| Количество педработников | Число |
| Ссылка на сайт | Текст/URL |
| Широта | Число |
| Долгота | Число |
| Адрес | Текст |
| Район | Текст |
| Итоговый балл в мотивирующем мониторинге за 2024 г. | Число (для строк-районов) |
| Тип учреждения | Текст |

Колонки `ID` / `Порядковый номер` распознаются и игнорируются.

### Произвольные колонки

Любая колонка, не входящая в обязательный список, добавляется на дашборд автоматически. Тип определяется по значениям:

- **Процентная** (среднее по району/срезу, %): колонка с Excel-форматом `0.0%` (или `0%`), либо если хотя бы в одной ячейке встречается знак `%`. Диапазон значений неважен — могут быть и `0.85`, и `85`, и `"85%"`.
- **Булевая** (доля «Да», %): значения «Да/Нет» (рекомендуется именно так), а также «+/−», `true`/`false`, `0`/`1`. **Пустая ячейка считается за «Нет»** — это влияет на знаменатель агрегата.
- **Числовая** (сумма по району/срезу): прочие числа.

> Чтобы избежать путаницы, заполняйте булевые колонки единообразно — **«Да» / «Нет»**. Пустые ячейки автоматически трактуются как «Нет».

### Строки vs строки-районы

Строка считается **школой**, если есть сайт либо обе координаты (широта + долгота).

Если строка не школа, но её название соответствует известному району, это **строка-район** — её значения используются как fallback и подставляются ТОЛЬКО когда по школам этого района нет данных по этой колонке. Прочие строки (`ИТОГО по ЧР` и т.п.) пропускаются.

### Тип учреждения и фильтр

Уникальные значения колонки «Тип учреждения» превращаются в радио-кнопки на главной (плюс «Все учреждения»). Выбор фильтрует таблицы и сводки; цветовая карта районов (по баллу мониторинга) всегда показывает все школы.

«Итоговый балл в мотивирующем мониторинге» влияет на цвет района: красный `< 85`, жёлтый от `85` до медианы (не включая), зелёный `≥` медианы. Медиана считается по баллам всех районов и пересчитывается при загрузке новых данных.
