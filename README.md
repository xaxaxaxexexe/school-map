# Школы Чеченской Республики

Веб-приложение для мониторинга школ Чеченской Республики. Дашборд со статистикой по районам и интерактивная карта на Яндекс.Картах.

Работает полностью на клиенте — сервер не нужен. Данные загружаются из Excel-файла прямо в браузере.

## Стек

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 4
- Redux Toolkit
- Яндекс.Карты 2.1
- SheetJS (xlsx) — парсинг Excel на клиенте
- PWA (офлайн-поддержка)

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка

```bash
npm run build
npm run preview
```

Готовый билд в `dist/` — можно хостить как статический сайт (GitHub Pages, Netlify, Vercel и т.д.).

## Загрузка данных

1. Перейти на `/admin`
2. Загрузить `.xlsx` файл (drag-and-drop или клик)
3. Файл парсится в браузере и сохраняется в localStorage
4. Данные доступны на дашборде (`/`) и карте (`/map`)

## Формат Excel

Файл `.xlsx`, первая строка — заголовки, данные со второй строки. 22 колонки (A–V):

| Колонка | Описание | Тип |
|---------|----------|-----|
| A | Порядковый номер | Число |
| B | Название школы | Текст |
| C | Смена | Число |
| D | Мощность (мест) | Число |
| E | Кол-во учащихся | Число |
| F | Кол-во работников | Число |
| G | Кол-во учителей | Число |
| H | Сайт школы | Текст/URL |
| I | Широта | Число |
| J | Долгота | Число |
| K | Адрес | Текст |
| L | Район/Департамент | Текст |
| M | Государственная | Да/Нет |
| N | Религиозная | Да/Нет |
| O | Кол-во зданий | Число |
| P | Отремонтирована | Да/Нет |
| Q | Требует ремонта | Да/Нет |
| R | Аварийное состояние | Да/Нет |
| S | Обуч. во 2 смену | Число |
| T | Строится | Да/Нет |
| U | ШНОР | Да/Нет |
| V | Школа с необъективностью | Да/Нет |

Строка загружается если заполнено хотя бы одно из: район (L) или координаты (I + J).

## Структура проекта

```
src/
├── components/          # UI-компоненты
│   ├── ui/              # Переиспользуемые элементы
│   ├── dashboard/       # Компоненты дашборда
│   ├── Layout.tsx       # Обёртка роутера
│   ├── Sidebar.tsx      # Боковая панель карты
│   └── YandexMap.tsx    # Карта Яндекс
├── pages/               # Страницы
│   ├── DashboardPage    # Главная — статистика
│   ├── MapPage          # Карта школ
│   └── admin/           # Загрузка данных
├── store/               # Redux (dataSlice)
├── lib/                 # Утилиты и хуки
│   ├── format.ts        # Форматирование (fmt, yesNo, statusClass...)
│   ├── excelParser.ts   # Парсер Excel

│   ├── useTheme.ts      # Тёмная/светлая тема
│   └── ymaps.ts         # Загрузчик Яндекс.Карт
├── data/                # Геоданные районов, GeoJSON границ
└── types/               # TypeScript типы
```
